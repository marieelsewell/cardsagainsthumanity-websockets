## cardsagainsthumanity-websockets

My mobile-friendly Cards Against Humanity web application delivers a seamless and engaging multiplayer experience, leveraging Node.js, Express, and Vue.js. Designed with a responsive interface, it ensures smooth gameplay on smartphones and tablets, allowing players to join virtual game rooms effortlessly. WebSockets power real-time communication, enabling instant card submissions and interactions among players. The backend, built with Node.js and Express, handles game logic, user sessions, and card randomization, ensuring a fair and dynamic experience. Vue.js drives the frontend, providing an intuitive and visually appealing interface where players can swipe through cards, select answers, and view scores with minimal latency.

The game replicates the irreverent humor of Cards Against Humanity, with a digital twist tailored for online play. Players can connect, allowing friends or strangers to compete in private or public matches. The WebSocket-driven architecture supports low-latency updates, so players experience near-instant feedback as they submit cards or judge rounds.
